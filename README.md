# CMS Phase-2 Outer Tracker (SiDet FNAL)

This repository is used by the CMS Phase-2 Outer Tracker team at SiDet FNAL to investigate and track issues.

## Issue Tracking Workflow

Use GitHub Issues to log work and progress:

- **Investigation** issues: document observed behavior, context, findings, and next steps.
- **Task** issues: track actionable follow-up work from investigations.

Issue templates are provided under `.github/ISSUE_TEMPLATE` to keep reports consistent and searchable.
